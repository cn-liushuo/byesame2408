# .cursor

| 需求场景                   | 推荐配置项                   | 原因                                   |
| -------------------------- | ---------------------------- | -------------------------------------- |
| 固定代码规范(如TypeScript) | rules(.cursor/rules)         | 需持续约束 AI 输出，避免每次重复提醒   |
| 高频工作流(如生成组件)     | skills(.cursor/skills)       | 封装完整流程，减少重复描述             |
| 排除敏感文件               | .cursorignore(.cursorignore) | 安全刚需，必须手动配置                 |
| 扩展AI能力                 | mcp                          | 需要外部系统集成，rules/skills无法实现 |
